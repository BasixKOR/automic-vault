# databricks Detector

## Trigger Conditions

- Databricks config contains plaintext profile credentials.

## Sensitive Files

- `~/.databrickscfg`
- `$XDG_CONFIG_HOME/databricks/config`
- `$XDG_CONFIG_HOME/databricks/databrickscfg`
- `~/.config/databricks/config`
- `~/.config/databricks/databrickscfg`
