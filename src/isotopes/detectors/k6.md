# k6 Radioisotope

k6 can store a Grafana Cloud token in its user config JSON.

This radioisotope migrates the cloud token into the Automic Vault keychain,
removes the token from the local config JSON, and wraps `k6` so
`K6_CLOUD_TOKEN` is injected only while k6 is running. Non-secret config fields
are preserved in the original config file.

## Caveats

- We currently migrate config files that contain a non-empty top-level `token`.
- If a token is written back into the config JSON, the detector will report it
  again.
- Direct execution of the original binary will not receive the credentials.
