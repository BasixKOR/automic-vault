# yt-dlp Detector

## Trigger Conditions

- yt-dlp netrc file contains plaintext credentials.
- yt-dlp config contains plaintext password options.

## Sensitive Files

- `~/.netrc`
- `$XDG_CONFIG_HOME/yt-dlp/config`
- `$XDG_CONFIG_HOME/yt-dlp.conf`
- `~/.config/yt-dlp/config`
- `~/.config/yt-dlp.conf`
- `~/.yt-dlp.conf`
