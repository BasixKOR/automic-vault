API key management for AI coding agents

Automic Vault treats API keys as capabilities that should reach the approved tool, not the agent transcript. Store tokens locally, inject only named keys, and gate the commands that can use them.

Scope

API keys need command-level boundaries.

Agents are useful because they can run CLIs, SDKs, package managers, and deploy tools. Those tools often need API keys. The key should be available to the tool invocation without becoming readable context for the model.
