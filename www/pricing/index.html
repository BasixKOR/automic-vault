Why free

The product is local infrastructure, not another hosted vault bill.

Automic Vault runs on the developer Mac because that is where agents can read files, invoke CLIs, and mutate local package state. The free release focuses on closing those local hazards before they become transcript leaks or unreviewed tool actions.

Local first

No central secret source to replace

Keep using your existing password manager or cloud secret system. Vault protects the local execution point where tools ask for credentials.

Open source

Review the code path

The security boundary is easier to trust when the installer, CLI behavior, and package hardening logic can be inspected in public.

Agent era

Protect the developer workstation

The Mac that runs agents is now part of the security perimeter. Pricing stays simple while that local boundary is still being established.
