01 · Harden

Make installs immutable. Make plaintext secrets disappear.

Automic Vault installs packages into controlled roots, links the command you run through an av shim, and hardens supported tools so credentials move out of easy-read files.

gh awscli curl git npm terraform kubectl mcp

02 · Securing .env files

Keep dotenv convenient without leaving plaintext for agents.

av dotenv reads and writes dotenvx-compatible encrypted: values. The private key lives in the Automic Vault Keychain, and exports ask for approval before keys enter a shell or command.

03 · macOS app

A local console for packages, approvals, and updates.

Automic Vault.app keeps the terminal workflow visible: Touch ID for privileged installs and updates, notifications when packages need attention, and package dossiers with homepages, versions, hazards, and security notes.
