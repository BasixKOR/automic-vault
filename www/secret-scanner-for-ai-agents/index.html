Local credential discovery

The secret scanner for AI agent machines

Run av secret-scanner before an agent session to find plaintext credentials in tool configs, dotenv files, shell profiles, and Automic Vault package-specific detectors.

Last updated: June 1, 2026

An AI agent secret scanner should find plaintext credentials before the agent run starts. Automic Vault scans likely local secret paths, then pairs detection with runtime controls that prevent repeated plaintext exposure.

Agent-visible files

Scan the files local coding agents can read.

Repository scanners are useful, but agent exposure often starts in the developer home directory: CLI auth files, package manager config, cloud credentials, and environment files.

From finding to fix

Find plaintext secrets, then move them.

Find

av secret-scanner reports high-confidence plaintext credentials without printing the secret value itself.

Move

av save KEY stores credentials outside files that an agent can casually read.

Inject

av inject +KEY /abs/tool gives the credential to the approved executable, not to the model transcript.

When to scan

Use scanning as a preflight, not as the only control.

A scanner is useful because it catches mistakes already sitting on disk. It is not enough by itself. Once a secret is found, the next step is to move it out of the readable file path and make future use happen through an approved tool execution.

Before agent runs

Scan the workstation before giving an agent broad filesystem access or asking it to debug a local project.

After tool installs

New CLIs and package managers often create auth files. Leave Vault running so new hazards are visible quickly.

After remediation

Run the scanner again after moving credentials into Vault to confirm old plaintext paths are no longer the easy route.

FAQ

Secret scanner questions.

Automic Vault pairs discovery with hardening. The scanner tells you what an agent can see; Vault then helps remove supported plaintext paths and gate credential use.

Coverage

What does the scanner check?

It checks likely local secret paths, tool configs, project files, and package-specific detectors for plaintext credential exposure.

Limits

Is scanning enough?

No. Scanning finds exposure. Automic Vault also moves supported credentials out of plaintext files and gates approved tool execution.

Timing

When should I run it?

Run it before agent sessions, after installing new developer tools, and when local configuration changes might expose credentials.
