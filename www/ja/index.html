Homebrew 作者による macOS セキュリティ

AI エージェントにローカルの鍵を渡さない。

Automic Vault は、AI コーディングエージェントが使うシークレット、CLI、パッケージインストールを macOS 上で制御するローカル実行レイヤーです。

Download Docs

シークレットを平文ファイルから移動

API キー、クラウド認証情報、GitHub トークンを .env やシェル設定から取り出し、承認されたツールだけに渡します。

危険なコマンドに人間の承認を追加

公開、インフラ変更、トークン表示、その他の高リスク操作を、エージェントが実行する前に確認できます。

パッケージ実行面を把握

生成されたパッケージカタログは、CLI、インストール経路、承認ゲート、シークレットリスクのシグナルをクロール可能なページとして公開します。
