Why install it

before the next agent run
Homebrew tools

Find what installed tools can read

Homebrew makes developer tools easy to add. Automic Vault checks the tool layer those packages create and reports credential paths, package hazards, and approval opportunities before an agent reaches them.

Plaintext files

Move supported secrets out of easy reach

Tokens in .env, .npmrc, .netrc, AWS config, and GitHub CLI state are convenient for humans and readable for local processes. Vault moves supported credentials into protected local storage.

Approval gates

Ask before commands use power

Package publishing, token reveal, cloud mutation, and installer execution should not be silent agent side effects. Automic Vault puts the approval where the command runs, below the agent prompt.

After install

scan, harden, monitor
1 / scan

Run the secret scanner first

Use the scanner to surface plaintext credential files and package-specific hazards before an autonomous coding session starts.

2 / harden

Patch the package surface

Move supported credentials into Vault, keep command stubs under a predictable root, and leave old easy-read file paths out of the agent's reach.

3 / monitor

Keep Vault running

New installs, stale tools, and fresh local config can reopen holes. The running app keeps reporting hazards so you can close them quickly.

Works with the tools already on your Mac

local boundary
Package managers

Homebrew, npm, and PyPI remain familiar

Automic Vault does not ask you to abandon normal developer tooling. It adds scanner output, package metadata, hardened roots, and approval points around the tools agents are most likely to call.

Team vaults

Use central secret stores where they fit

1Password, HashiCorp Vault, and cloud secret systems can remain the source of truth. Automic Vault controls the local moment when a CLI, script, or package command tries to receive those credentials.

Agents

Put the boundary below the prompt

Agent-side policy is useful, but a compromised or confused agent controls its own prompt surface. Vault keeps the approval and secret boundary at the local tool layer where execution happens.
