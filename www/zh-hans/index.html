Homebrew 作者打造的 macOS 安全层

保护你用 brew install 装上的工具。

Automic Vault 在 AI 代理使用之前，在你的 Mac 本地保护 Homebrew 工具、CLI 密钥和命令审批门。

密钥会留在 Keychain 支持的存储中，直到已批准的工具需要它们。

危险工具操作可以在执行时要求人工审批。

发布版安装位于 /opt，并通过 /usr/local/bin 中的稳定 stub 入口运行。

亮点

安全地图
01 / secrets 不再有可被代理抓取的明文凭据文件。 02 / approval 审批位于敏感工具操作实际执行的位置。 03 / packages 代理工具链获得加固的 root 和传递依赖栈。 04 / trace 在 curl-pipe-shell 安装器写入文件前进行检查。

核心边界

当代理可以在你的 Mac 上运行工具时，真正改变的部分。

v0 范围
1

Keychain 支持的密钥

工具获得密钥。代理不会。

Automic Vault 为关键工具加入边界，让凭据离开明文文件并进入本地受保护存储。工具继续工作，代理失去简单读取路径。

  • gh
  • aws-cli
  • av inject
  • secret scanner
2

人工审批门

审批应位于代理之下，而不是代理内部。

代理内置控制有帮助，但被攻破的代理会控制自己的策略面。Automic Vault 将门放在本地工具层，也就是令牌导出、软件包发布和其他敏感操作实际运行的位置。

Automic Vault代理想要运行： npm publish 批准吗？拒绝批准
3

Nucleus 软件包管理器

把代理工具安装到它无法重写的 root 中。

Nucleus 将 Homebrew、npm 和 PyPI 软件包安装到加固 root。代理可以运行已批准工具，但不会把开发环境变成可随意写入的环境状态。

HomebrewnpmPyPI/opt
4

明文暴露扫描

运行前找出代理能看到什么。

av secret-scanner 会搜索已经暴露在本地文件中的凭据。在给自主运行授予广泛文件访问前，可用它做快速预检。

用于软件包控制的原生 Mac 界面。

搜索软件包、检查元数据、用 Touch ID 批准安装、跟踪更新；当终端更合适时使用 av CLI。
