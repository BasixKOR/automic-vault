Homebrew 作者打造的 macOS 安全层

不要把本地密钥交给 AI 代理。

Automic Vault 是 macOS 本地运行时控制层，用来约束 AI 编码代理使用的密钥、CLI 和软件包安装。

Download Docs

让密钥离开明文文件

API 密钥、云凭据和 GitHub 令牌不再留在 .env 与 shell 配置中，只会注入到已批准的工具。

为高风险命令加入人工审批

发布、基础设施变更、令牌显示等敏感操作可在代理执行前先由人确认。

理解软件包执行面

生成的软件包目录把 CLI、安装路径、审批门和密钥风险信号发布为可抓取页面。
